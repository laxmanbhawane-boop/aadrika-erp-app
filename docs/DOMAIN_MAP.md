# Domain Map

foundation, identity, organization, permissions, audit, workflow, notifications, documents, settings

## Commercial
CRM, customers, quotations, pricing, sales orders, invoicing, receivables

## Supply Chain
suppliers, purchasing, RFQ, purchase orders, GRN, inventory, warehouse, logistics

## Manufacturing
BOM, routing, MRP, PPC, production orders, work orders, shop floor, WIP

## Industry
printing, artwork, prepress, plates/screens, ink, make-ready, packaging, finishing, bag costing

## Quality
incoming QC, process QC, final QC, NCR, CAPA, complaints

## Assets
machines, fixed assets, maintenance, tools, spares, AMC, warranty

## Finance
GL, AP, AR, banking, GST, expenses, cost centres, profitability

## Intelligence
reports, MIS, dashboards, analytics, AI automation

## Data flow
CRM -> Quotation -> Sales Order -> MRP -> Procurement/Production -> QC -> Inventory -> Dispatch -> Invoice -> Finance.
